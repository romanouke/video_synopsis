Memadatkan kejadian video panjang lewat temporal rearrangement object tubes.

Upload video, lalu sistem akan mendeteksi objek bergerak, membentuk tube dengan BoT-SORT-style tracking, menyusun ulang timeline, dan menghasilkan output yang memperlihatkan kejadian berbeda secara bersamaan selama collision tetap rendah.

Pipeline

  2. Object detection
  3. Object tracking
  4. Object tube extraction
  5. Tube filtering / cleaning
  6. Temporal rearrangement / optimization
  7. Foreground extraction
  8. Background generation
  9. Foreground + background compositing
  10. Video encoding
  11. Preview + download

Tujuan project

Fokus project ini adalah demonstrasi konsep Video Synopsis, bukan sekadar memilih keyframe. Object tubes dari waktu berbeda dapat ditumpuk pada timeline hasil jika tidak saling collision secara signifikan.

Implementasi ini memakai pendekatan motion-based detection agar ringan untuk demo dan mudah dikembangkan ke detector yang lebih canggih.
